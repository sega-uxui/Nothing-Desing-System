# Product Context

## Users
- Frontend developers and designers building modern web applications
- Teams looking for a production-ready design system
- Companies needing consistent UI components across multiple projects
- Developers who value accessibility, performance, and type safety

## Product Purpose
A minimal, production-ready design system built for modern web applications. Provides comprehensive component library, design tokens, and theming capabilities to help teams ship faster with better components.

## Brand Voice
- Professional yet approachable
- Technical but clear
- Confident and precise
- Developer-focused

## Strategic Principles
- Performance first: Zero runtime CSS-in-JS, instant hot reload
- Accessibility by default: WCAG 2.1 AA compliant
- Type safety: Full TypeScript support with strict types
- Composable architecture: Every component built to compose and extend
- Framework agnostic: Works with any React-based stack

## Anti-References
- Avoid generic SaaS design patterns (hero metrics, gradient cards)
- No glassmorphism or overly decorative effects
- Skip cliché tech startup aesthetics
- Avoid overly complex animations that hurt performance
- No nested card layouts or identical card grids
